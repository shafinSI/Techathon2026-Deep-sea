# Wokwi circuit files

`diagram.json` (this folder) is the importable Wokwi circuit, and
`wokwi.toml` points Wokwi at the compiled firmware when using the
[Wokwi CLI](https://docs.wokwi.com/vscode/getting-started) or VS Code
extension instead of the web editor.

**Full instructions, the complete firmware listing, and the complete
circuit listing all live in one place: `../../HARDWARE.md`, Section 8
("Wokwi Virtual Simulation").** That section is self-contained — copy
the two code blocks from there straight into wokwi.com and it runs.

This folder exists so the same files are also available as plain,
directly-importable project files (e.g. for the Wokwi CLI, or to avoid
copy-pasting out of a Markdown file by hand).
